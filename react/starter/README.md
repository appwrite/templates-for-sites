# Getting Started with React and Vite

This project uses [React](https://react.dev/) with [Vite](https://vite.dev/) as its build tool.

## Available Scripts

In the project directory, you can run:

### `npm run dev`

Runs the app in the development mode.\
Open [http://localhost:5173](http://localhost:5173) to view it in your browser.

The page will reload when you make changes.

### `npm test`

Launches the [Vitest](https://vitest.dev/) test runner in the interactive watch mode.

### `npm run build`

Builds the app for production to the `build` folder.\
It correctly bundles React in production mode and optimizes the build for the best performance.

The build is minified and the filenames include the hashes.\
Your app is ready to be deployed!

### `npm run preview`

Serves the production build from the `build` folder locally so you can check it before deploying.
