# Changelog

## 0.7.5

- Update vulnerable framework and build dependencies across the templates.
- Migrate the React starter to Vite, Remix to React Router 7, VuePress to
  VuePress 2, and React Native to Expo SDK 58 while preserving the starter apps.
- Add the Appwrite Jaspr starter.
- Repair both Lynx web wrappers for the upgraded web runtime and include its
  required `@lynx-js/lynx-core` dependency.
- Update `markdown-it` to 15.0.3 in all four Lynx lockfiles.
- Build the Lynx web wrappers and VitePress documentation in template CI.
- Enable weekly dependency updates and automatic merging of eligible patch
  and minor updates after required checks pass.

Changes since [0.7.4](https://github.com/appwrite/templates-for-sites/releases/tag/0.7.4).
